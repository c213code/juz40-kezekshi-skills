# Білім қоры: қайталанатын жағдайлар

Мұнда кезекшілік кезінде қайта-қайта кездесетін жағдайлар жиналады (5-қадам).
Әр жазба: **белгісі → себебі → қалай тексеріледі → не істеледі**. Жеке деректер жазылмайды.
