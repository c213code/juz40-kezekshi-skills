# 1-қадам. Өтінішті қабылдау және сұрыптау

**Мақсаты:** іздеуді бастамас бұрын не болғанын, кімде болғанын және қаншалықты шұғыл
екенін түсіну.

## Не істейсің

1. Хабарламаны және барлық тіркемені оқы. Скриннен көрінгеннің бәрін шығар: сабақ/тест
   атауы, статус, қате мәтіні, уақыт, Request ID, құрылғы.
2. Пайдаланушыны анықта: логин/почта/телефон, рөлі. Почтадағы анық қатені (мысалы,
   `gamil.com`) өзің түзет, бірақ мұны айт.
3. Санатын анықта:
   - кіру / аккаунт
   - төлем / оферта / шарт
   - оқу: сабақ, балл, прогресс, дедлайн
   - тест / сынақ (сынақ ҰБТ, квиз)
   - көрсету / интерфейс / құрылғы
   - жаппай ақау («платформа істемей тұр»)
   - «қалай жасаймын» сұрағы — баг емес
4. Шұғылдығын анықта:
   - **жоғары:** жаппай ақау, ақша, тест/сынақ дәл қазір жүріп жатыр
   - **орташа:** бір пайдаланушы, айналып өту жолы жоқ
   - **төмен:** айналып өту жолы бар, сұрақ, тілек
5. Дубльді тексер: бұл сессияда немесе Jira-да ұқсас өтініш болды ма.

## Шығыс

```
Мәні: пайдаланушы не күтті → орнына не болды
Кім: логин / рөл
Санат: ...
Шұғылдығы: ...
Не жетпейді: ... → авторға сұрақ: «...»
Дубль: ...
```

## Ережелер

1. Кімде мәселе екені белгісіз болса — іздеуді бастама, алдымен сұрақ қой.
2. Бір мәселе туралы бірнеше адам жазса — бұл бір мәселе, шұғылдығы жоғары.
3. «Қалай жасаймын» — бірден жауап бер, диагностикасыз.
4. Чаттағы пароль мен жеке деректі қолданба және қайталама.
