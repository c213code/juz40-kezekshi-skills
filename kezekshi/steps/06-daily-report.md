# 6-қадам. Журнал және дейли-репорт

**Мақсаты:** кезекші күні бойы ештеңе қолмен жазбайды. Әр өтініш журналға түседі,
кешке скилл өзі репорт ұсынады.

## Журнал (әр өтініштен кейін)

4-қадам біткен соң (шешім мен жауап дайын) — журналға бір жол қос:

```bash
python3 scripts/journal.py add --group "<чат/топ атауы>" \
  --desc "<не болды — қысқа, жеке деректерсіз>" \
  --status <RESOLVED|IN_PROGRESS|PENDING|NEXT_DAY|ESCALATED> \
  --note "<репортқа жазылатын статус мәтіні>" [--link <чаттағы хабарлама сілтемесі>] [--ticket DV-XXXX]
```

| Жағдай | status | note мысалы |
|---|---|---|
| Жауап берілді, мәселе жабылды | `RESOLVED` | «Ерош шешті, балл қойылды» |
| Әлі тексеріліп жатыр | `IN_PROGRESS` | «Қарап жатырмыз» |
| Біреуден жауап күтеміз | `PENDING` | «Оқушыдан скрин күтеміз» |
| Ертең қараймыз | `NEXT_DAY` | — |
| Әзірлеушіге / басқа командаға берілді | `ESCALATED` | «Передано: Backend» + `--ticket` |

Кейін статус өзгерсе: `journal.py list` → `journal.py update <N> --status RESOLVED --note "..."`.

`desc` және `note` — репортқа кететін мәтін: почта, телефон, ИИН, пароль жазба.
Оқушыны «оқушы» деп немесе топ атымен атаса жеткілікті.

## Репорт уақыты

Әр өтінішті өңдеп болған соң `python3 scripts/journal.py due` іске қос.
`YES` болса (18:00-ден кейін, бүгін репорт әлі жасалмаған) — кезекшіден сұра:

> Сағат 18:00-ден өтті, бүгін N өтініш болды. Дейли-репортты дайындайын ба?

Кезекші келіссе:
1. `journal.py list` — `IN_PROGRESS` тұрғандарды кезекшімен бір-бірлеп нақтыла
   (шешілді ме, ертеңге ме), керек болса `update`.
2. `python3 scripts/journal.py report --duty "<кезекші аты>"` — дайын мәтін.
3. Мәтінді кезекшіге **көшіруге дайын блокпен** бер. Telegram-ға өзің жіберме —
   кезекші өзі жібереді.

Кезекші «кейін» десе — қайта сұрама, ол өзі «репорт» деп жазады.

## Ережелер

1. Журналға тек өңделген өтініш түседі (4-қадамнан кейін) — ойдан жазба қоспа.
2. Репорт мәтінін өзгертпей бер; кезекші түзетсе — `update` арқылы, сосын қайта `report`.
3. Репорт тек кезекшінің растауымен жасалады және тек ол жібереді.
