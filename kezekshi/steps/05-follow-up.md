# 5-қадам. Өтініштен кейін: Jira және білім қоры

**Мақсаты:** бір рет түзетілген мәселе ұмытылмасын, келесі кезекші де білсін.

## Не істейсің

1. **Кодтағы баг немесе қайталанатын мәселе** → кезекшіге `bag-jira` скиллімен тапсырма
   ашуды ұсын (дайын сценарий, себебі, ауқымы бар).
2. **Жаңа жағдай** (ережелерде жоқ, бірақ тағы қайталануы мүмкін) → кезекшіге ұсын:
   «Мұны `references/cases.md`-ге қосайық па?» Келісім болса — 3–5 жолмен қос:
   белгісі, себебі, қалай тексеріледі, не істеледі. Скилл осылай толығады.
3. **Ауысым соңы** (кезекші сұраса) → қысқа есеп:
   ```
   Жабылды: N (қысқаша тізім)
   Ілулі тұр: ... (кімде, не күтеді)
   Jira-ға кетті: ...
   Келесі кезекшіге: ...
   ```

## Ережелер

1. Бір себеп — бір тапсырма; Jira-да дубль жоқ екенін тексер.
2. Білім қорына тек жалпы, қайталанатын жағдайларды қос — бір реттік оқиғаны емес.
3. Білім қорында жеке деректер (почта, телефон, ИИН) болмайды.
