# 2-қадам. Багты қайталау

**Мақсаты:** баг шынымен бар екеніне және қандай шартта шығатынына көз жеткізу.

## Не істейсің

Карточка бойынша кез келген адам қайталай алатын сценарий құр:

```
Алғышарттар: рөл, аккаунт, құрылғы/браузер, күйі (курс төленген, дедлайн өткен...)
Қадамдар:
  1. ... ашу
  2. ... басу
Күтілген нәтиже: ...
Нақты нәтиже: ...
```

Кезекші қадамдарды өтеді (немесе сен дерек/лог арқылы растайсың) және нәтижені жазады:

- **Қайталанды** → 3-қадам.
- **Қайталанбады** → пайдаланушының жағдайы немен ерекшеленеді: құрылғы, браузер,
  уақыт, рөл, деректер. Бір шартты ауыстырып қайта көр.
- **Тек осы пайдаланушыда** → мәселе оның деректерінде болуы ықтимал.

## Браузер арқылы қайталау (Claude өзі қарайды)

Сессияда браузер құралы болса (Claude қосымшасындағы браузер немесе Claude in Chrome),
пайдаланушының аккаунтын Claude өзі қарап шыға алады.

1. **Админ ретінде кіру.** Платформаны аш. Кезекші админ аккаунтымен өзі кірмеген болса —
   кіруді сұра. Логин мен парольді **кезекші өзі** енгізеді, сен енгізбейсің.
2. **Пайдаланушы аккаунтына кіру.** `https://juz40-edu.kz/admin/impersonation` бетін аш,
   «Email» өрісіне пайдаланушының почтасын қой. **Құпия сөзді кезекші өзі енгізіп,
   «Кіру» басады.** Кезекшіге айт: «Құпия сөзді енгізіп кіріңіз, кірген соң "кірдім" деп жазыңыз».
3. «Кірдім» дегеннен кейін — қайталау қадамдарын өзің өт: сабақты/тестті аш, статусты,
   қате мәтінін, күндерді оқы, скрин ал. Күтілгенмен салыстыр.
4. Нәтижені жаз (қайталанды / жоқ / тек осы пайдаланушыда) және кезекшіге айт:
   «Тексердім, аккаунттан шығыңыз» — немесе өзің «Шығу» бас.

Ескерту:
- Impersonation осы браузердегі админ сессиясын ауыстырады. Кезекшілікке бөлек браузер
  профилі ыңғайлы — өз админкаңнан шығып кетпейсің.
- Пайдаланушының өз сессиясы үзілмейді (ол өз құрылғысында қала береді).
- Ішіндегі әр әрекет **пайдаланушының атынан шын жасалады** — сондықтан тек қарау.

Браузер құралы жоқ болса — кезекші өзі кіріп, скрин жібереді; сен скриннен оқисың.

## Ережелер

1. Баг бар жерде қайталанады — көбіне пайдаланушының продтағы аккаунтында (команданың
   қолданыстағы тәртібімен). Тек **қарау**: тест тапсыру, жауап жіберу, «Сақтау»,
   «Растау», «Жіберу», «Тапсыру», төлем, профильді өзгерту — жоқ. Бұл пайдаланушының
   деректері мен рейтингінде қалады. Пароль мен құпия сөзді ешқашан өзің енгізбе.
2. Әрекет жасау керек болса — ұқсас жағдайдағы тест аккаунтта жаса немесе
   пайдаланушыдан экран жазбасын сұра.
3. Қадамдарды контекст білмейтін адам қайталай алатындай жаз.
4. Бір уақытта бір ғана шартты өзгерт.
5. Қайталанбаса — бұл да нәтиже: не тексерілгенін және пайдаланушыдан не керегін жаз.
6. Дайын сценарий өзгеріссіз Jira тапсырмасына және регресс тест-кейсіне өтеді.
